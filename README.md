# Memory-Cache-Simulator
This project involves the development of a Real-Time Cache Simulator designed to model the intricate behavior of a CPU's memory hierarchy during active execution. Moving beyond traditional trace-driven simulations that rely on static log files, this simulator operates on a dynamic request stream, mimicking the live interaction between a processor's Load/Store units and the cache controller. The implementation supports various architectural configurations, including Direct-Mapped, Set-Associative, and Fully-Associative structures, while enforcing sophisticated data consistency through Write-Back and Write-Through policies. A primary focus of the simulator is its cycle-accurate latency modeling, which calculates the performance impact of cache hits versus the heavy penalties associated with main memory fetches (misses). By integrating replacement algorithms like LRU (Least Recently Used) and managing metadata such as valid and dirty bits, the project provides a comprehensive environment for analyzing the trade-offs between cache size, associativity, and effective memory bandwidth in modern computing systems.
